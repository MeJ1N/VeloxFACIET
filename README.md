# Lunex Upgrader — FINAL

Готовая GitHub Pages demo-версия CS2 skin upgrader.

## Файлы

- `index.html` — разметка.
- `style.css` — весь интерфейс и адаптив.
- `script.js` — каталог, инвентарь, кейсы, апгрейдер, история и LocalStorage.
- `.nojekyll` — корректная работа GitHub Pages.

## Установка в GitHub

1. Удали старые `index.html`, `style.css`, `script.js`.
2. Загрузи новые файлы в КОРЕНЬ репозитория.
3. В Settings → Pages выбери `Deploy from a branch`, ветку `main`, папку `/ (root)`.
4. Сохрани и подожди завершения GitHub Actions.
5. Открой опубликованный URL и нажми `Ctrl + F5`.

## Скины

Каталог получает реальные названия и изображения CS2 из публичного CSGO-API/Counter-Strike Image Tracker. Если API временно недоступен, включается резервный набор.

## Важно

Это только виртуальная демонстрация. Баланс виртуальный, реальные деньги, Steam-трейды и вывод средств не подключены.
