# Lunex Upgrader

Готовая статическая demo-версия в стиле современных skin-upgrader интерфейсов.

## Важно
Сайт не является копией upgrader.pro: дизайн сделан самостоятельно, но использует похожую общую концепцию тёмного интерфейса, карточек, рулетки и апгрейдера.

## Что работает
- Апгрейдер: выбор своего предмета + цели.
- Реальный для демо расчёт шанса.
- Кнопка «АПГРЕЙД» запускает анимацию и результат.
- При победе целевой предмет добавляется в инвентарь.
- При проигрыше исходный предмет удаляется.
- Кейсы.
- Инвентарь.
- История.
- Сохранение через localStorage.
- Адаптивность для телефона.

## Установка в GitHub
Загрузите `index.html`, `style.css` и `script.js` в корень репозитория и сделайте commit.
GitHub Pages должен быть настроен на ветку `main` и папку `/ (root)`.

Это виртуальная демо-версия без реальных денег, Steam API, депозитов и вывода.
