Lunex Cases — готовая демо-версия
=====================================

Запуск:
1. Распакуйте ZIP.
2. Откройте index.html в браузере.

Возможности:
- Кейсы
- Случайные предметы и редкости
- Баланс
- Инвентарь
- Апгрейдер
- Сохранение через localStorage
- Мобильная адаптация

Важно:
Это клиентская DEMO-версия. Для реального проекта с авторизацией,
донатом и защищённым балансом нужен backend.
